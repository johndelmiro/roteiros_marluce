# Método de Roteiro de Aulas - John Delmiro

Este repositório contém um site de página única para auxiliar na criação de roteiros de vídeo aulas. O usuário preenche as informações da aula e gera um PDF com o roteiro final.

## Como usar

1. Abra `index.html` em um navegador ou publique o repositório no GitHub Pages.
2. Preencha os campos de curso, módulo, título e os textos de introdução, desenvolvimento e encerramento.
3. Clique em **Gerar Roteiro** para visualizar o conteúdo.
4. Utilize **Baixar PDF** para salvar ou imprimir o roteiro gerado.

O site inclui também um checklist para gravação de aulas online.
